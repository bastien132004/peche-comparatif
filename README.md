# PêcheComparatif

Comparateur de matériel de pêche en eau douce, construit avec Astro.

## Démarrer

```bash
npm install
npm run dev
```

Les produits sont centralisés dans `src/data/products.ts`. La page d'accueil fournit la recherche, le filtrage par catégorie et une sélection locale pour comparer les produits.
